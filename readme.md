## Description
-Mediclic est une application de type médicale pour des patients.
-Elle répond à un besoin urgent du marché et constitue un atout pour tous individus.
- Mediclinic , l'application qui s'occupe de la gestion des cliniques

- Framework utilisés: Flutter
- Outils de gestion de données : Firebase, 

## Fonctionnalités:
- Maps
- Les prises de rendez-vous
- Urgence : une gestion des urgences médicales
- Notifications push.
- Chatbot
- Gestion des cliniques

## Utilisation

Design leger et simpliste

1.cloner le repo
***
    bash
      git clone git@github.com:medenou/medi.git
***


2.Installer les dépendances
***
    bash
    flutter pub get
***


3.Lancer le projet
***
   bash
   flutter run
***
